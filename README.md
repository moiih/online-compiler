# ProLang Online Compiler

This is one of my favourite 🌟 and also the most interesting web project that I really enjoyed working on. This web app simply allows its users 👩‍💻 to execute multiple programs written in a variety of languages from a single interface at anytime and from anywhere without bothering to switch between different IDEs dedicated for different programming languages or having to use heavy editors like VS Code for running small independent programs or code snippets.
As of now the application has support for the following frequently-used languages like C, C++, Java☕ and Python🐍, but is scalable and has capability to support more programming languages on-demand.

- ### 💡Story & Idea Behind Starting This Project: 👇
  - When I was learning programming and my teacher taught something new about any programming language *(which was 'C' initially)*, my mind always used to get filled up with a long queue of thoughts, questions and some random thing to test out myself, but I couldn't because having to wait for the next Lab Period in the week just killed my curiosity and the innovative thought used to just vanish.
  - So, I, even without having idea about the 'W' of "Web Development", wrote this thought of *creating a website through awhich I (or anyone who loves to code) could go and type their code and get the output on the go regardless of being I am in college, auto, bus or anywhere outdoors, I just wanted the freedom to code and put the random but innovative code snippets into action without having to carry the whole Computer Lab (I mean laptop or PC) all the time. And not just that, I kept this secret only to myself and I didn't even google it because I did not want this idea to be leaked to Google through search before I complete it. I thought that I was the first one to discover it, so kept it in my mind like a patent without a digital footprint 👣*.
  - However, one of my close friends in college broke my illution by showing me an app (TurboC for Android app) through which anyone could run the C and C++ codes on his/her phone easily. This really had me think again.
  - But I didn't gave up, even after implicitly knowning that some sort of website would already be existing on the internet, I made this web app and completing this app, atleast just for me, was *like a dream that came to life*.
